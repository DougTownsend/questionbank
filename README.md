# Question Bank

A local, single-user app for curating Moodle question banks. Import questions
generated by an external Claude (or any source that produces Moodle XML),
preview each one as Moodle would render it, approve or reject with free-text
notes, then assemble assignments and export back to Moodle XML. Rejection notes
will be used to refine future question generation.

The app never calls Claude itself — you run Claude separately, it writes XML
files into the class directory, the app ingests them. Per-class `CLAUDE.md`
and `BANK_CONTEXT.md` files are generated for you to feed back into Claude
on the next round.

## Requirements

- Linux (other Unix-likes probably work; untested)
- Python 3.10 or newer
- ~30 MB of disk for dependencies

## Install

```bash
git clone https://github.com/DougTownsend/questionbank.git ~/claude_projects/question_bank
cd ~/claude_projects/question_bank

python3 -m venv .venv
.venv/bin/pip install -e '.[dev]'

# optional: make the command available everywhere
ln -sf $(pwd)/.venv/bin/question-bank ~/.local/bin/question-bank
```

Confirm it works:

```bash
question-bank list
```

## Usage

### 1. Start the app

```bash
question-bank            # start the server (browser NOT opened automatically)
question-bank --browser  # start the server and auto-open the UI in your default browser
```

The UI is at `http://localhost:8765`. Ctrl-C in the terminal to stop.

### 2. Create a class

On the home page, type a class name and click **Create class**. Whitespace
becomes underscores (`ECE 212` → `ECE_212`), filesystem-unsafe characters
are stripped. This creates:

```
~/question_bank/classes/<class>/
├── bank.sqlite        # all questions, assignments, rejection notes
├── materials/         # you drop lecture transcripts, slides, PDFs here
├── imports/           # Claude writes its generated XML here
└── exports/           # the app writes assignment XML here
```

### 3. Generate questions with Claude

```bash
cd ~/question_bank/classes/<class>
claude                                 # launch Claude in this directory
```

`CLAUDE.md` tells Claude the workflow, supported question types, the exact
Moodle XML format to produce, **and the schema of `bank.sqlite` with example
`sqlite3` queries**. Claude queries the database directly to see what's
already approved or rejected (and your rejection notes), so there's only
one source of truth.

`CLAUDE.md` is regenerated automatically when you create a class and on
every app startup, so the instructions stay in sync with the app version.

Ask Claude something like:

> Read the files in `materials/` and generate 10 multiple-choice and 2
> numerical questions on cache write policies. Save the XML to `imports/`.

Claude will write a file to `imports/<date>_<topic>.xml`.

### 4. Import and review

Back in the app:

1. Open your class → **Import XML** → pick the file from `imports/`.
2. Go to **Review queue**. For each question:
   - **A** or click **Approve**
   - **R** or click **Reject** (optionally type a note in the text area first
     — the note gets saved with the question and shown to Claude in the next
     `BANK_CONTEXT.md`)
3. Once every question from that file is approved or rejected, the XML file
   is automatically deleted from `imports/`.

### 5. Build an assignment

On the class dashboard, click **Assignments** → **Create assignment**.

In the assignment detail page:
- Left pane: questions currently in the assignment (click **Remove** to drop one)
- Right pane: your approved bank, filterable by type, category, and a text
  search. Click **Add** to append to the assignment.
- **Rename** changes the assignment title.
- **Export XML** writes a Moodle-importable file to
  `~/question_bank/classes/<class>/exports/<assignment_name>.xml`.
- **Delete assignment** removes the assignment; questions stay in the bank.

Import the exported XML into Moodle via
**Course → Question bank → Import → Moodle XML format**.

## CLI reference

```bash
question-bank                           # start the web UI (default)
question-bank --browser                 # start the web UI and auto-open your browser
question-bank list                      # list class names on this machine
```

`CLAUDE.md` is refreshed automatically on class creation and on every
app startup. Claude reads current bank state straight from `bank.sqlite`,
so no pre-rendered snapshot file needs to be kept up-to-date.

The data root defaults to `~/question_bank/`. Override with
`QUESTION_BANK_ROOT=/some/other/path question-bank`.

## Syncing between computers with Syncthing

Everything lives under `~/question_bank/` — sync that directory and you have
the same question banks on every computer.

### Install Syncthing on both machines

```bash
sudo apt install syncthing
systemctl --user enable --now syncthing
```

Web UI on each: `http://localhost:8384` (opens automatically on first run).

### Pair the two computers

1. On computer A, open the web UI. In the top-right, click **Actions → Show ID**.
   Copy the long ID string.
2. On computer B, open the web UI. Click **Add Remote Device**, paste the
   ID, give it a name (e.g. "laptop"), Save.
3. Computer A will show a notification asking to accept computer B. Accept.

### Share the bank directory

On whichever computer currently has your data:

1. Click **Add Folder**.
2. Folder path: `/home/doug/question_bank`
3. Folder label: `question-bank`
4. On the **Sharing** tab, check the other computer.
5. Save.

On the other computer, you'll see a prompt to accept the shared folder —
point it at the same path (`/home/doug/question_bank`) and accept. Changes
made on either machine now sync automatically over your local network or the
internet.

### Important: don't run the app on both machines at once

SQLite isn't designed for simultaneous access from two writers. Close the
app on one machine, wait a few seconds for Syncthing to catch up, then open
on the other. If you break this rule you risk corrupting `bank.sqlite`.

## Data layout

```
~/question_bank/                         # data root (sync this with Syncthing)
└── classes/
    └── ECE_212/
        ├── bank.sqlite                  # questions, assignments, notes (Claude queries this directly)
        ├── CLAUDE.md                    # instructions for external Claude (regenerated)
        ├── materials/                   # your course materials (add freely)
        ├── imports/                     # XML/JSON files Claude generated (auto-cleaned)
        └── exports/                     # assignment XML for import into Moodle
```

The code repo (`~/claude_projects/question_bank/`) is separate from the data
and holds no per-class info — safe to put on GitHub.
